# MM-RAG

MM-RAG is a Multi-Modal Retrieval-Augmented Generation (RAG) project for outfit matching.
It enables users to upload outfit images and ask questions about matching looks in a curated
database. The application returns the closest match based on color, style, and overall vibe.

## What this project does

- Accepts user-uploaded outfit images.
- Uses multi-modal understanding to represent visual outfit attributes.
- Retrieves similar outfits from a database using RAG-style retrieval.
- Responds with the best match and relevant fashion insights.

## Example use case

1. A user uploads an image of an outfit.
2. The system analyzes visual signals (e.g., palette, cut, style cues, vibe).
3. It queries the outfit database for the closest matching candidates.
4. The user receives the closest match with contextual information.
